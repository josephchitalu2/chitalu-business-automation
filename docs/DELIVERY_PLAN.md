# Delivery Plan

## Agreed product goal
A complete operations product with demonstrable credit, cash and approval workflows, secure user access, usable interfaces, documentation and tested recovery.

## Milestones
1. Implement domain objects, monetary validation, repositories and versioned schema.
2. Complete the credit-sale/repayment/statement workflow and meaningful tests.
3. Add authentication, role permissions, CSRF protection and secure configuration before shared use.
4. Add daily reconciliation, expenses and approval/payment separation.
5. Add persistent tasks, scheduling and reports; do not send customer messages without an agreed communication policy and configured provider.
6. Verify UI, concurrency/retries, permissions, backup restoration and deployment persistence.
7. Pilot with a business, document outcomes and maintain release history.

Each milestone must identify implemented behavior, test evidence and remaining work. No prototype should be described as a full production release.
